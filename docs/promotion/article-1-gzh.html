⚠️ 免责声明
本工具仅是一个启动器，用于方便地启动 DeepSeek Harness。它不是 DeepSeek 官方产品，与 DeepSeek 公司无关。功能上只是帮你运行 dsh 命令，不涉及任何模型训练或数据处理。
DeepSeek Launcher 是一个开源的桌面启动器，帮你更方便地使用 DeepSeek Harness。
它能做什么
✅ 双击启动，自动运行 dsh
✅ 支持 Windows、macOS、Linux
✅ 体积小巧（仅 642KB）
✅ 关闭窗口后后台继续运行
✅ 自动检查更新
📌 重要说明
1. 本工具不包含任何 AI 模型或数据
2. 本工具不处理任何用户数据
3. 本工具只是启动 dsh 的便捷方式
4. 所有 AI 功能由 DeepSeek Harness 提供
5. 本工具开源免费，代码在 GitHub 公开
怎么用
方式一：脚本版（需要 Node.js）
下载脚本，双击运行即可。

方式二：桌面版（推荐）
从 GitHub 下载对应平台的压缩包，解压后双击运行。
